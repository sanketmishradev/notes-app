# 📝 Notes App

A fully functional notes application built with HTML, CSS and JavaScript with a beautiful dark UI.

## ✨ Features

- Create, edit and delete notes
- Color tag your notes (Important, Ideas, Tasks, Personal)
- Search notes by title or content
- Data saves automatically in browser (Local Storage)
- Shows total notes and today's notes count
- Fully responsive — works on mobile too!
- No backend needed — works completely offline!

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Local Storage API

## ▶️ How to Run

1. Download `notes_app.html`
2. Open it in any browser
3. Start adding notes — no setup needed!
